A LITTLE GUIDE TO GHOSTTY

Ghostty、
ここからはじめよう。

文字でMacを操作する「ターミナル」。
黒い画面も、使い方がわかれば大丈夫。
よく使う操作から、ひとつずつ覚えましょう。

最初の一歩へショートカット早見表 ↗
you — zsh
~ ❯ pwd
/Users/you

~ ❯ ls
Desktop Documents Downloads

~ ❯
まずは、これだけでOK。

入力する → Enterを押す → 結果が出る。

むずかしい言葉は少なめはじめてでも読める解説
その場で試せるブラウザの中で操作を練習
あとから見返せる操作と設定をひとまとめ
01

FIRST STEPS

まずは、3つだけ。

設定はあとで大丈夫。Ghosttyを開いて、最初のコマンドを実行してみましょう。

STEP 01

Ghosttyを開く

アプリケーションからGhosttyを起動。文字とカーソルが表示されたら、準備完了です。

~ ❯ここに入力します
STEP 02

pwd と入力する

「今、どのフォルダにいる？」と聞くコマンドです。半角で入力してください。

pwd
STEP 03

Enterで実行する

/Users/あなたの名前 のような場所が出れば成功。次の入力待ちに戻ります。

↳/Users/you

「❯」「%」「$」は、入力していいよの目印。これは「プロンプト」と呼びます。見本と形が違っても大丈夫。コマンドだけ入力して、Enterを押します。

まだインストールしていない場合
  1. 公式ダウンロードページからmacOS版のDMGをダウンロードします。
  2. DMGを開き、Ghosttyを「アプリケーション」へドラッグします。
  3. アプリケーション内のGhosttyを開きます。

Homebrewを使っている場合は brew install --cask ghostty でも導入できます。公式のインストール案内 ↗

02

TALK TO YOUR TERMINAL

「見る」と「移動する」から。

まず覚えたい5つのコマンド。矢印を押すと、右の練習画面で試せます。

pwd
今いる場所を表示迷ったら、まずこれ。
ls
ファイルの一覧を見る今いるフォルダの中身を表示。
cd Desktop
Desktopへ移動ホームにいるときの例。cdの後に空白。
cd ..
ひとつ上のフォルダへ「..」は、親フォルダのこと。
clear
画面の表示をすっきりファイルを削除する操作ではありません。

小さなコツ　↑ で前のコマンドを呼び出せます。
Ghosttyでは Tab で名前の補完もできます。
cd ~ なら、どこからでもホームに戻れます。

ブラウザで練習
ここは練習用の、小さなターミナル。
「pwd」と入力して、Enterを押してみましょう。
練習用の仮想フォルダです。Macのファイルは変わりません。

Ghosttyは「画面」、シェルは「命令を解釈する係」。このコマンドは、Ghosttyの中で動くzshなどのシェルが扱います。macOS標準の「ターミナル」でも、同じように使えます。

03

MAKE SOME ROOM

作業する場所を、増やそう。

切り替えて使うなら「タブ」。並べて見たいなら「分割」。

分割したら、使いたい画面をクリック。
⌘ + W で、今選んでいる分割画面を閉じられます。分割していなければタブを閉じます。

05

MAKE IT YOURS

見やすさを、自分好みに。

配色と文字サイズを試して、気に入った設定をコピー。まずは小さな変更から。

配色を選ぶ

このガイド独自の配色例です。プレビューはイメージで、実際のフォントや表示とは異なります。Ghosttyの設定は自動では変更されません。

your little workspace
# ちょうどいい、を見つけよう。
~ ❯ pwd
/Users/you
~ ❯
設定ファイルに追加する内容
font-size = 15
window-padding-x = 16
window-padding-y = 16
background = 18271f
foreground = eaf1e7
cursor-color = d7f18c
1.設定を開く⌘ + ,

Ghosttyで押すと、設定ファイルが開きます。

2.貼り付けて保存

同じ項目があれば、その値を書き換えます。編集したファイルを保存しましょう。

3.再読み込みする⌘ + ⇧ + ,

余白の変更は、新しく開いたタブで確認できます。

設定ファイルの場所・反映されないとき

macOSでは通常、~/Library/Application Support/com.mitchellh.ghostty/config.ghostty が使われます。旧形式の config も対応しています。迷ったら ⌘ + , で開いたファイルを編集してください。

~/.config/ghostty/config.ghostty などのXDG側のファイルも読み込みます（XDG_CONFIG_HOME未設定の場合）。両方に同じ項目があると、あとに読み込まれるmacOS側の設定が優先されます。

文字サイズをショートカットで変更した画面では、設定のサイズ変更がすぐに反映されないことがあります。新しいタブで確認してください。ほかの設定にはアプリの再起動が必要なものもあります。設定の公式ガイド ↗

06

WHEN YOU GET STUCK

困ったら、ここを見てみよう。

最初につまずきやすいところを集めました。

Q.コピーしようとして、処理が止まった

Macでコピーするキーは ⌘ + C。文字を選択してから押します。Control + C は、多くのコマンドで「中断」の意味になります。

Q.「command not found」と表示される

入力した名前のコマンドが見つからない、という意味です。つづり・半角英数字・余分な記号を確認しましょう。ツールによっては、Ghosttyとは別にインストールが必要です。

ghostty 自体が見つからず、アプリを通常の場所に入れている場合は、/Applications/Ghostty.app/Contents/MacOS/ghostty +list-keybinds --default で標準キー一覧を確認できます。

Q.「No such file or directory」で移動できない

その場所に、指定したフォルダが見つかりません。pwd で現在地、ls で中身を確認しましょう。ホームのDesktopへ移動するなら cd ~/Desktop。名前に空白がある場合は cd "My Folder" のように引用符で囲みます。

Q.パスワードを入力しても、何も表示されない

ターミナルでのパスワード入力は、文字や「●」が表示されないことがあります。入力は受け付けられているので、入力を終えたらEnterを押します。

Q.画面が動かない・入力できない

まず、入力したい分割画面をクリック。コマンドの実行中なら Control + C で中断を試せます。less などの閲覧画面なら Q で戻れます。別の作業を始めたい場合は ⌘ + T で新しいタブを開いてください。

Q.ショートカットを忘れてしまった

⌘ + ⇧ + P でコマンドパレットを開くと、操作を名前で探せます。画面上部のメニューでも操作とキーを確認できます。このガイドはmacOS向けで、Linuxではキーの割り当てが異なります。

今日は、ひとつ使えたら十分。

まずは pwd、ls、cd。慣れたら、タブや分割も試してみましょう。
